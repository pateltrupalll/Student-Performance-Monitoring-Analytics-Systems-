# Student Performance Analysis 🎓📊
This project is a web-based Student Performance Analysis System designed to monitor and manage student academic performance, learning modules, attendance, quizzes, and leave requests.
The system provides separate dashboards for students and administrators, making it easier to track student progress and manage academic activities through an interactive and user-friendly interface.

1. Key Features
- Student and Admin Login Authentication
- Student Performance Dashboard
- Admin Dashboard for overall student monitoring
- Learning Module Management
- Student-wise Module Progress Tracking
- Quiz Attempt Tracking
- Attendance Management
- Leave Request and Approval Management
- Student Performance Monitoring
- Quick Actions for better navigation
- Interactive and user-friendly dashboard
- Separate access and functionality for Students and Admins

 2. Tools & Technologies

- Student Login

- Admin Dashboard
- View Total Students
- Manage Learning Modules

- Review Leave Requests
- Monitor Student Performance

 4. Objective
The main objective of this project is to develop a centralized system for monitoring student performance and academic activities.
It helps administrators efficiently manage students, modules, attendance, quizzes, and leave requests while allowing students to track their own learning progress and performance.

5. Project Benefits
- Reduces manual student performance tracking
- Centralizes academic information
- Makes attendance and leave management easier
- Helps administrators monitor student progress
- Provides students with quick access to their performance
- Improves overall academic activity management
